# Changelog

All notable changes to PWDS are documented here.

## 1.2.0 - 2026-11-21

- Added a documented compatibility matrix and official documentation links for Codex, Claude Code, Cursor, and Gemini CLI.
- Added a dependency-free installer with project/user scopes, dry-run, safe skip behavior, and explicit force replacement.
- Added five original SVG visual references covering composition, typography, semantic color, responsive reflow, and interaction states.
- Added five repeatable benchmark briefs and a baseline-versus-PWDS evaluation protocol.
- Expanded structural validation to cover skills, benchmarks, visual assets, installer presence, and release version consistency.
- Corrected the README repository map, installation instructions, roadmap, and package version.

## 1.1.0 - 2026-11-21

- Added ten specialist skills covering typography, color, imagery, conversion, interaction, motion, dashboards, e-commerce, mobile web, and visual regression.
- Expanded the README skill catalogue, repository map, and roadmap.

## 1.0.0 - 2026-11-21

- Initial public release of the modular Premium Website Design Skills pack.
- Added orchestrator and six specialist skills.
- Added four design profiles, critique references, anti-patterns, and browser verification guidance.
- Added structural validation script and GitHub Actions workflow.
